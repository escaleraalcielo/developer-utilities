Salesforce stores all DateTime values in UTC internally. When you query a DateTime field, you see the UTC representation. This tool helps you convert between UTC, your local timezone, Unix epoch, and the formats you commonly see in APIs (ISO 8601, Salesforce query results, debug logs).
Input without a timezone (e.g. 2024-01-15 10:30:00 or 2024-01-15) is assumed to be UTC.
