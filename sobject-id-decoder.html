SObject ID Decoder

Decode a Salesforce record ID to its 3-char prefix and likely SObject. Supports 15 and 18-char IDs, bulk decode.

ID Type Prefix SObject Format
Salesforce record IDs are made of a 3-character object prefix + 12 chars of org/record data (+ optional 3-char case-safe checksum for 18-char IDs). Per-org custom object prefixes (typically starting with a or e) are detected heuristically — to get the exact SObject name for a custom prefix, query SELECT KeyPrefix, SObjectType FROM EntityDefinition in your org.
